01

De objeto para texto e de volta

JSON é um formato de texto para troca de dados. Suas chaves e strings usam aspas duplas; não há comentários nem vírgula após o último item. JSON.stringify() transforma dados compatíveis em uma string; JSON.parse() interpreta um texto JSON.

JSON não preserva tudo que existe em JavaScript: funções e undefined não são representados como propriedades de objeto, e datas são normalmente serializadas como strings. Texto inválido em JSON.parse() causa um erro.

Exemplo prático
JavaScript
const tarefa = { titulo: "Revisar arrays", concluida: false };
const texto = JSON.stringify(tarefa);
console.log(texto);
const recuperada = JSON.parse(texto);
console.log(recuperada.titulo);
console.log(recuperada.concluida);

02

Persistência com cuidado

localStorage guarda pares de chave e valor como strings, associados à origem do site. getItem() retorna null se a chave não existir. Os dados costumam permanecer entre visitas, mas podem ser apagados pelo usuário ou bloqueados pelo navegador. Não use para senhas nem outros segredos.

Use try...catch para tratar JSON inválido, bloqueio de armazenamento e falta de espaço. Valide o formato recuperado: um JSON válido não significa que os dados têm a estrutura esperada.

Os exemplos deste curso rodam em um iframe isolado sem acesso ao armazenamento da página principal. Por segurança, localStorage pode ser bloqueado ali. O exemplo trata essa situação; para testar a persistência real, copie o código para uma página servida por HTTP no seu próprio ambiente. O progresso do curso usa o armazenamento da página principal separadamente.

Exemplo prático
JavaScript
const chave = "curso-js:preferencias-demo";
try {
  const preferencias = { tema: "claro" };
  localStorage.setItem(chave, JSON.stringify(preferencias));
  const texto = localStorage.getItem(chave);
  const dados = texto === null ? null : JSON.parse(texto);
  if (dados && typeof dados.tema === "string") {
    console.log("Tema salvo:", dados.tema);
  }
  localStorage.removeItem(chave); // limpa apenas esta chave de teste
} catch (erro) {
  console.log("Armazenamento indisponível ou dados inválidos:", erro.message);
}
Veja o resultado no console de saída

03

JSON não preserva todos os tipos de JavaScript

Em objetos, propriedades com undefined ou funções são omitidas por JSON.stringify. Em arrays, posições com undefined são representadas como null. NaN e Infinity também são serializados como null. JSON.parse não restaura comportamentos, métodos ou tipos especiais automaticamente.

Objetos Date usam uma representação textual de data na serialização habitual. Se precisar trabalhar de novo com métodos de data, reconstrua e valide esse valor na leitura. Referências circulares e bigint sem tratamento específico fazem stringify lançar erro.

Não use JSON.parse(JSON.stringify(objeto)) como uma solução universal de cópia: ela perde informações e só funciona para certos dados. Para persistir o projeto, escolha uma estrutura simples de strings, booleanos e listas de objetos com campos conhecidos.

Exemplo prático
JavaScript
const registro = {
  titulo: "DOM",
  observacao: undefined,
  numeroInvalido: NaN,
  criadoEm: new Date("2026-01-15T12:00:00Z")
};
const texto = JSON.stringify(registro);
console.log(texto);
const lido = JSON.parse(texto);
console.log(typeof lido.criadoEm); // string
console.log(Object.hasOwn(lido, "observacao")); // false
console.log(JSON.stringify([undefined])); // [null]
Veja o resultado no console de saída

04

Validação de formato e versão dos dados

Um JSON pode ser sintaticamente válido e ainda ter o formato errado, como um número no lugar de uma lista. Valide o contêiner e cada campo necessário antes de usar os dados. Evite copiar indiscriminadamente propriedades externas para objetos de configuração.

Um envelope com versao e itens permite reconhecer o formato salvo. Quando a estrutura mudar, você pode migrar versões antigas conhecidas ou oferecer uma recuperação clara. Não trate qualquer formato desconhecido como se fosse a versão atual.

O exemplo lê dois formatos conhecidos e reconstrói os itens usando apenas campos esperados. A versão antiga usa strings; a nova usa objetos com título e conclusão. Uma migração real também precisa definir como lidar com IDs, duplicação e limites do domínio.

Exemplo prático
JavaScript
function lerRegistro(texto) {
  const dados = JSON.parse(texto);
  if (!dados || !Array.isArray(dados.itens)) {
    throw new Error("Registro sem lista de itens.");
  }
  if (dados.versao === 1 && dados.itens.every((item) => typeof item === "string" && item.trim() !== "")) {
    return { versao: 2, itens: dados.itens.map((titulo) => ({ titulo: titulo.trim(), concluida: false })) };
  }
  if (dados.versao === 2 && dados.itens.every((item) => item && typeof item.titulo === "string"
    && item.titulo.trim() !== "" && typeof item.concluida === "boolean")) {
    return { versao: 2, itens: dados.itens.map((item) => ({ titulo: item.titulo.trim(), concluida: item.concluida })) };
  }
  throw new Error("Versão ou itens incompatíveis.");
}
try {
  console.log(lerRegistro('{"versao":1,"itens":["DOM","Eventos"]}'));
} catch (erro) {
  console.log("Não foi possível recuperar:", erro.message);
}
Veja o resultado no console de saída

05

localStorage, sessionStorage e eventos entre abas

localStorage é compartilhado por documentos da mesma origem e normalmente persiste entre sessões. sessionStorage também é separado por origem, mas fica associado à sessão de uma aba; normalmente sobrevive a recargas e é descartado ao encerrar essa sessão. Nenhum deles é armazenamento seguro de segredos.

As operações dessas APIs são síncronas e podem bloquear a execução enquanto trabalham. Para listas pequenas isso costuma ser suficiente; dados grandes e consultas complexas pedem outras soluções, como IndexedDB, que está fora do escopo deste projeto.

O evento storage é entregue a outros documentos que compartilham aquela área de armazenamento, não à própria janela que fez a gravação. A demonstração abaixo trata um evento sintético, apenas para exercitar o handler no sandbox; para observar a comunicação real de localStorage, use duas abas da mesma página fora do iframe.

Sincronizar abas não resolve conflitos automaticamente: duas abas podem gravar versões diferentes e a última gravação substituir a anterior. Defina uma estratégia de recarga, aviso ou conciliação antes de prometer colaboração em tempo real.

Exemplo prático
JavaScript
function receberMudanca(event) {
  if (event.key !== "estudos:estado:v2") return;
  try {
    const dados = event.newValue === null ? null : JSON.parse(event.newValue);
    console.log("Mudança observada:", dados);
  } catch (erro) {
    console.log("Mudança ignorada: JSON inválido.");
  }
}
window.addEventListener("storage", receberMudanca);
// Simulação local: não grava e não representa uma segunda aba real.
window.dispatchEvent(new StorageEvent("storage", {
  key: "estudos:estado:v2",
  newValue: '{"versao":2,"itens":[]}'
}));
Veja o resultado no console de saída

! Erros comuns

  • Salvar um objeto diretamente e obter a string "[object Object]".
  • Achar que localStorage é um banco de dados seguro ou sincronizado entre dispositivos.
  • Confundir JSON válido com dados válidos para a aplicação.
  • Esperar que storage dispare na janela que fez a gravação.

✓ Boas práticas

  • Use chaves com prefixos específicos do projeto.
  • Trate erros e confira o formato dos dados recuperados.
  • Versione os formatos e reconstrua apenas os campos permitidos.
  • Ofereça recuperação e backup antes de descartar dados antigos ou incompatíveis.

// Mesmos dados das etapas anteriores. Agora a página reflete o estado.
const aluno = "Lia";
const minutosPorAssunto = Number("25");
let assuntos = [
  { id: "1", titulo: "Variáveis", concluida: true },
  { id: "2", titulo: "Funções", concluida: false },
  { id: "3", titulo: "DOM", concluida: false },
  { id: "4", titulo: "Eventos", concluida: false }
];
const lista = document.querySelector("#lista-estudos");
const aviso = document.querySelector("#aviso");
const chave = "js-em-pratica:projeto-evolutivo:v1";
const persistencia = document.querySelector("#persistencia");
try {
  const texto = localStorage.getItem(chave);
  if (texto !== null) {
    const dados = JSON.parse(texto);
    const validos = Array.isArray(dados) && dados.length <= 100 && dados.every((item, indice) =>
      item && typeof item.id === "string" && item.id.trim() !== "" &&
      typeof item.titulo === "string" && item.titulo.trim().length >= 1 && item.titulo.length <= 80 &&
      typeof item.concluida === "boolean" && dados.findIndex((outro) => outro?.id === item.id) === indice
    );
    if (!validos) throw new Error("Formato inválido");
    assuntos = dados.map(({ id, titulo, concluida }) => ({ id, titulo, concluida }));
  }
  persistencia.textContent = "Armazenamento disponível neste navegador.";
} catch (erro) {
  persistencia.textContent = "Sem dados salvos válidos. O plano continua funcionando nesta sessão.";
}
function salvar() {
  try {
    localStorage.setItem(chave, JSON.stringify(assuntos));
    persistencia.textContent = "Plano salvo neste navegador.";
  } catch (erro) {
    persistencia.textContent = "Não foi possível salvar. Alterações apenas nesta sessão.";
  }
}
let proximoId = 5;
function criarId() {
  while (assuntos.some((item) => item.id === String(proximoId))) proximoId++;
  return String(proximoId++);
}
const campo = document.querySelector("#novo-assunto");

function calcularPercentual(feitas, total) {
  if (total === 0) return 0;
  return Math.round((feitas / total) * 100);
}
function atualizarResumo() {
  const feitas = assuntos.filter((item) => item.concluida).length;
  document.querySelector("#nome-aluno").textContent = aluno;
  document.querySelector("#total").textContent = String(assuntos.length);
  document.querySelector("#concluidas").textContent = String(feitas);
  document.querySelector("#tempo").textContent = assuntos.length * minutosPorAssunto + " min";
  document.querySelector("#progresso").value = calcularPercentual(feitas, assuntos.length);
}
function registrarMudanca(mensagem, focoId = null) {
  salvar();
  renderizar(focoId);
  aviso.textContent = mensagem;
}
function renderizar(focoId = null) {
  lista.replaceChildren();
  const visiveis = assuntos;
  for (const assunto of visiveis) {
    const item = document.createElement("li");
    const titulo = document.createElement("span");
    titulo.textContent = assunto.titulo;
    const rotulo = document.createElement("label");
    const checkbox = document.createElement("input");
    checkbox.type = "checkbox";
    checkbox.dataset.id = assunto.id;
    checkbox.checked = assunto.concluida;
    checkbox.addEventListener("change", () => {
      assunto.concluida = checkbox.checked;
      registrarMudanca("Conclusão atualizada.", assunto.id);
    });
    rotulo.append(checkbox, titulo);
    const excluir = document.createElement("button");
    excluir.type = "button";
    excluir.className = "secundario";
    excluir.textContent = "Excluir";
    excluir.setAttribute("aria-label", "Excluir " + assunto.titulo);
    excluir.addEventListener("click", () => {
      assuntos = assuntos.filter((outro) => outro.id !== assunto.id);

      registrarMudanca("Assunto excluído.");
      campo.focus();
    });
    item.append(rotulo, excluir);
    lista.append(item);
  }
  document.querySelector("#vazio").hidden = visiveis.length !== 0;
  atualizarResumo();
  if (focoId !== null) {
    const controle = Array.from(lista.querySelectorAll("input")).find((elemento) => elemento.dataset.id === focoId);
    (controle ?? aviso).focus();
  }
}

document.querySelector("#adicionar-form").addEventListener("submit", (event) => {
  event.preventDefault();
  const titulo = campo.value.trim();
  if (titulo.length < 1 || titulo.length > 80 || assuntos.length >= 100) {
    aviso.textContent = "Use de 1 a 80 caracteres. O limite do plano é 100 assuntos.";
    campo.focus();
    return;
  }
  assuntos.push({ id: criarId(), titulo, concluida: false });
  campo.value = "";
  registrarMudanca("Assunto adicionado.");
  campo.focus();
});

renderizar();

Converta uma lista de dois assuntos para JSON e reconstrua a lista.

Preciso de uma dica

Combine JSON.stringify() e JSON.parse().

Uma solução possível
JavaScript
const assuntos = ["DOM", "Eventos"];
const texto = JSON.stringify(assuntos);
const lista = JSON.parse(texto);
console.log(Array.isArray(lista)); // true
console.log(lista);

03

Escreva uma função que reconheça uma lista de tarefas com titulo string não vazia e concluida booleano.

Preciso de uma dica

Confirme primeiro Array.isArray e depois use every.

Conferir uma solução possível +
Uma solução possível
JavaScript
function ehListaValida(dados) {
  return Array.isArray(dados) && dados.every((item) =>
    item && typeof item.titulo === "string" && item.titulo.trim() !== ""
    && typeof item.concluida === "boolean"
  );
}
console.log(ehListaValida([{ titulo: "DOM", concluida: false }])); // true
console.log(ehListaValida([{ titulo: "", concluida: "não" }])); // false
Veja o resultado no console de saída

04

Crie um backup JSON com versão 1 e uma lista de assuntos; leia-o tratando erro e versão desconhecida.

Preciso de uma dica

Guarde versao junto dos itens e valide ambos depois do parse.

Conferir uma solução possível +
Uma solução possível
JavaScript
const backup = JSON.stringify({ versao: 1, assuntos: ["DOM", "JSON"] });
try {
  const dados = JSON.parse(backup);
  if (dados?.versao !== 1 || !Array.isArray(dados.assuntos)
    || !dados.assuntos.every((item) => typeof item === "string")) {
    throw new Error("Backup incompatível.");
  }
  console.log(dados.assuntos);
} catch (erro) {
  console.log(erro.message);
}
Veja o resultado no console de saída

GUARDE ESTAS IDEIAS

Em poucas palavras.

  • JSON transforma dados compatíveis em texto e permite reconstruí-los.
  • localStorage guarda strings por origem e pode estar indisponível.
  • Persistência exige tratamento de erros e validação dos dados lidos.
  • JSON preserva dados compatíveis, não funções, referências ou todos os tipos.
  • Formatos versionados e validação por campo permitem evoluir a persistência.
  • Armazenamento web é síncrono, pode falhar e não resolve conflitos entre abas.
