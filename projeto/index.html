Em vez de recomeçar em exemplos desconectados, acompanhe a construção do Meu plano de estudos. Cada módulo acrescenta uma peça ao mesmo projeto, preservando as versões anteriores.

16 versões executáveisHTML + CSS + JavaScriptArquivos completos e comparação

Como estudar nesta trilha

  1. Leia o assunto do módulo e a explicação da etapa.
  2. Preveja o resultado; depois abra a página ou compare com a versão anterior.
  3. Confira as alterações e copie os três arquivos se quiser experimentar uma mudança.

O CSS de apoio já está pronto e permanece igual. Nas etapas 1–10, os cálculos usam o console e o HTML evolui como estrutura estática. Na etapa 11 conectamos o DOM; depois chegam interação, formulário, persistência e assincronia. As etapas 14–16 compartilham os dados do projeto quando abertas fora da prévia.
